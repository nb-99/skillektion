# Source

Adapted from `pstack/skills/automate-me` in
[`cursor/plugins`](https://github.com/cursor/plugins) at commit
`60c641e4fad674784b30abcf9f8915dea39df38d`.

The adaptation replaces Cursor transcript paths, tools, mode-skill conventions,
and automatic publication with client-specific supported exports, explicit
session selection, privacy gates, and reviewable skill drafts. It restores the
upstream interview step, but allows the evidence to produce a focused skill or
a narrower instruction, check, or documentation artifact rather than always
creating one personal mode skill.
