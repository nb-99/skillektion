# Source

Adapted from `pstack/skills/technical-writing` in
[`cursor/plugins`](https://github.com/cursor/plugins) at commit
`df581122cde17e6e27686b5a448bde23e4ad4318`.

The source combines Diataxis, Google developer style, ASD-STE100 principles,
and Global English guidance. This version removes date-bound source claims,
mandatory sibling invocation, repository-specific indentation policy, and the
manual-only invocation restriction so clients can apply it while drafting or
reviewing technical prose. It incorporates concise pull-request briefing
guidance while retaining necessary reviewer evidence inline, allowing useful
small tables, and avoiding a rigid one-minute reading limit. The local review
checklist remains intact with a pull-request-specific completion check. Licensed
under the MIT terms in `LICENSE.upstream`.
